CSR Bluetooth fix for Linux 7.0

A patched btusb DKMS module for the unbranded CSR clone adapter tested on this host (0a12:0001). This repository carries only the Ubuntu Linux 7.0 source variant.

View the repository

What the patch changes

The adapter returns malformed HCI responses and has USB lifecycle problems. The patch masks commands the controller advertises but does not implement, pads several short Command Complete replies, adjusts runtime power management, and recovers from selected initialization failures with a USB reset. Its workarounds are limited to detected fake CSR adapters.

Install

Use an Ubuntu 7.0.x kernel and matching headers:

sudo apt install git dkms linux-headers-$(uname -r)
git clone https://github.com/k1moradi/bluetooth-driver.git
cd bluetooth-driver
sudo ./install.sh

The install script builds for the running kernel only. The module goes in /lib/modules/<kernel>/updates/dkms/; it does not overwrite the in-tree driver. This checkout rejects kernel versions outside 7.0.x.

Verify or uninstall

dkms status csr8510-fix
modinfo -F filename btusb
journalctl -k -b | grep -iE 'bluetooth|csr'
sudo ./uninstall.sh

Bluetooth capability on this host

The adapter currently reports HCI 2.0. HCI LE Read Buffer Size and LE Read Local Supported Features return Unknown HCI Command, so its active firmware does not expose Bluetooth LE. A host driver cannot add commands that the controller firmware rejects. The USB ID alone does not identify the adapter's silicon.

Razer documents Bluetooth and 2.4 GHz modes for the Naga V2 HyperSpeed, but does not specify whether its Bluetooth connection uses BR/EDR or LE. See Razer's specifications and pairing guide. Pairing over the controller's supported BR/EDR transport is still unverified. See the repository's host findings for the measurements.
